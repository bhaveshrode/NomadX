# NomadX Privacy Policy

**Effective Date:** September 2, 2026  
**Version:** 1.0.0

## 1. Data Collection
NomadX collects information necessary to deliver autonomous commerce services:
- **Account Information:** Email addresses, hashed credentials, full names, organization identifiers.
- **Operational Data:** Invoices, payment intent statuses, transaction hash references, webhook endpoint URLs.
- **Telemetry & Logs:** IP addresses, API user-agent headers, timestamped request metadata.

## 2. Use of Information
Collected data is used solely to:
- Authenticate users and enforce organization multi-tenancy.
- Execute automated dunning, invoicing, and settlement reconciliation workflows.
- Monitor system health, detect operational anomalies, and issue incident notifications.

## 3. Data Protection & Encryption
- Data in transit is secured using TLS 1.3 encryption.
- Secrets and tokens are hashed or encrypted at rest using industry-standard cryptographic algorithms.

## 4. Third-Party Data Sharing
NomadX does not sell customer personal data. Data is shared only with verified service providers (such as SMTP email delivery gateways or payment infrastructure processors) strictly as required to fulfill services.
